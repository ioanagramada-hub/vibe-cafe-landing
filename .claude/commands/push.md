Trimite commit-urile curente pe GitHub pentru proiectul Vibe Caffè. Te rog să faci următoarele:

1. Rulează `git status` pentru a verifica dacă există modificări necommitate
   - Dacă există modificări necommitate, anunță-mă și întreabă dacă să fac întâi un commit
   - Dacă nu există modificări necommitate, continuă

2. Rulează `git log origin/starter..HEAD` pentru a vedea câte commits urmează să fie trimise

3. Fă `git push` pe branch-ul curent

4. Confirmă că push-ul a reușit și afișează link-ul către repository-ul de pe GitHub: https://github.com/ioanagramada-hub/vibe-cafe-landing
